## 📌 Sobre o Curso

O curso é focado em ensinar a linguagem de programação mais popular do ecossistema web: o **JavaScript** (incluindo as atualizações do **ECMAScript**). Durante as aulas, são abordados desde os conceitos fundamentais de lógica e sintaxe até a manipulação dinâmica do DOM e funções avançadas.

---

## 📚 Módulos e Conteúdos

| Módulo | Conteúdo Principal | Projetos / Exercícios |
| :---: | :--- | :--- |
| **Módulo A** | Conhecendo o JS, Histórico, Instalação de Ferramentas (Node.js, VS Code) | Primeiros comandos e scripts simples |
| **Módulo B** | Comandos Básicos, Variáveis, Tipos de Dados, Operadores (Aritméticos, Relacionais, Lógicos e Ternário) | Interação com `alert`, `prompt` e formatação de dados |
| **Módulo C** | Entendendo o DOM (Document Object Model), Árvore DOM, Seletores e Eventos | Manipulação de elementos HTML e eventos do mouse/teclado |
| **Módulo D** | Condições em JS (`if`, `else`, `switch`) e Condições Aninhadas | ☀️ **Hora do Dia** <br> 🚗 **Verificador de Idade** |
| **Módulo E** | Repetições/Laços em JS (`while`, `do while`, `for`) | 🔢 **Contador** <br> ✖️ **Gerador de Tabuada** |
| **Módulo F** | Variáveis Compostas (Arrays), Funções e Introdução a Objetos | 📊 **Analisador de Números** |

## 🛠️ Tecnologias e Ferramentas Utilizadas

* **[JavaScript (ES6+)](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript):** Linguagem principal do curso.
* **[HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) & [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS):** Estrutura e estilização dos exercícios práticos.
* **[Visual Studio Code](https://code.visualstudio.com/):** Editor de código recomendado.
* **[Node.js](https://nodejs.org/):** Ambiente de execução JavaScript no lado do servidor.
